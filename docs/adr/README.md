# Architecture Decision Records (ADR)

This folder stores architecture decisions that affect implementation direction.

## Usage
1. Create a new file per decision using `NNNN-short-title.md` (example: `0001-authn-authz-approach.md`).
2. Record:
   - Status (`Proposed`, `Accepted`, `Superseded`)
   - Context
   - Decision
   - Consequences
3. Link related feature requirement docs from `docs/requirements/features/`.

## Why this exists
ADRs prevent repeated architecture debates and provide traceability for future feature work.
